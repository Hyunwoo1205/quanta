# 다단계 실험 실행 엔진 계획

작성일: 2026-11-04 · 기준 commit: `77f828b4bfee66c2b055c2272c47f43c4dda191a`

## 목표와 이번 범위

연구자가 작성한 단계·조건 변경·반복 축에 따라 기존 계산기를 실행하고, 실제 입력·결과·실패·재현 근거를 보존합니다. 단일 명령의 나열을 넘어 등록된 포트로 허용된 상태를 전달합니다. 기존 계산 모형의 과학적 범위를 그대로 유지하며 플랫폼 전체를 현재 모듈에 한정하지 않습니다.

이번 범위는 동기식 로컬 Python API·CLI, 결정적인 실행 계획, 분기·단계 실행, typed state와 실제 식별자·해시, 유효한 부분 결과와 번들 저장·검증·재실행입니다. 입력 계약 `0.2.0` 원본은 보존하고 실제 구현 상태·측정 근거는 별도 기록합니다. HTTP 서버·계정별 저장소·큐·동시 작업·취소 경쟁·24시간 멱등성·부분 체크포인트 재개·웹 화면은 이후 범위입니다.

## 결정한 실행 규칙

| 항목 | 결정 |
|---|---|
| 분기 순서 | 작성한 반복 축·값 순서의 Cartesian product; 분기 내부는 작성한 단계 순서 |
| 입력 해결 | 분기 기본 정의 → 반복 축 값 → 초기 또는 같은 분기의 앞선 성공 상태·정의 선택 → 현재 변경값 → 검증 |
| 초기 출처 | 매번 해당 분기의 기본 정의에서 시작; 다른 단계의 변경값을 승계하지 않음 |
| 앞 단계 출처 | 그 단계의 실제 성공 출력과 유효 정의를 승계; 반복 축을 다시 덮어쓰지 않음 |
| 원본 보존 | 초기·원래 출력·수정한 준비 입력·새 출력을 별도 상태로 보존 |
| 실패 전파 | 의존하는 단계만 건너뛰고 독립 단계·다른 분기는 계속; 전체 자원 한도는 남은 실행 중단 |
| 부분 결과 | 검증한 payload는 증거로 보존 가능; 실패·미수렴 payload를 후속 상태로 승격하지 않음 |
| 관측량 | 단계에 적용 가능한 요청만 선택; 교집합이 비어도 필수 solver 출력·상태는 계산 |
| 재실행 | 원본 입력과 고정한 계약·구현을 보존한 새 실행; 환경은 다시 관측하고 새 실행 지문에 반영 |

현재 실험 정의는 등록 모듈 하나를 선택합니다. 쌍 모듈의 배치는 다음 쌍 연산에 전달할 수 있고, 양자 정적 해는 계산 설정을 대신하지 않습니다. 양자 연산은 각 단계에서 초기 설정을 사용합니다. 모형 사이 물리적 결합이나 임의 변환은 추정하지 않습니다.

## 구현 순서와 완료 조건

1. **계획·바인딩:** 원본 정의·분기 기본값·상징적인 출처·등록 관측량·실제 구현을 고정합니다. 미래 출력·식별자를 계획에 넣지 않고 계약대로 계획 해시를 계산합니다.
2. **단계 실행:** 현재 입력을 검증한 뒤 준비 상태·출처 바인딩·단계 해시를 보존하고 계산합니다. 성공 시에만 출력 상태를 공개합니다. 수치·해상도·물리 검증 상태를 실행 성공과 분리합니다.
3. **근거·저장·재실행:** 코드·잠금·상수·정책·실제 환경·projection bytes·상태·산출물을 연결합니다. 저장한 UTF-8 자료의 실제 bytes를 검사하고 현재 신뢰한 코드가 고정 구현과 일치할 때만 재실행합니다.
4. **독립 검증·패키징:** 조건별 수동 기준, 승계·초기화·부분 결과·해시·변조 거부를 시험하고 실제 측정 기록을 남깁니다. 기존 수치 기준·회귀, 설치 패키지와 원격 CI도 통과해야 완료입니다.

원래 C01·C02·C04의 해당 부분을 실제 검증합니다. C03의 서버·취소 경쟁과 미구현 확장 시험은 완료로 표시하지 않습니다. 코드·결과 검증이 실제 현상에 대한 물리 검증을 대신하지 않습니다.

## 운영 경계

등록된 단계·분기 상한을 그대로 적용합니다. 단계 60초·전체 120초 및 더 낮게 고정한 정책을 계산 전후·내부 검사·최종 공개 경계에 연결합니다. 개별 LAPACK 호출은 협력적 검사 지점 사이에서 동작합니다.

저장 예산은 실제 번들 metadata bytes와 중복 제거한 내용 bytes입니다. 오류로 끝난 실행도 기록할 수 있도록 `8192*expanded_steps+4096` bytes를 말단 기록용으로 확보합니다. 과학 입력·결과를 잘라 맞추지 않고 초과 시 거부합니다. 초기 근거만으로 예산이 부족하면 실행 수락 전에 구조화 오류를 반환합니다.

현재 사용 방법과 실제 제공 범위는 [다단계 실행](workflows.md), 작업 결과와 다음 시작 지점은 [WORKPLAN](../WORKPLAN.md)에 연결합니다.

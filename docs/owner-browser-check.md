# 소유자 HTTPS 브라우저 확인

2026-11-06 · 앱 0.11.0 · 입력 계약 0.2.0

실제 배포는 Caddy 직접 HTTPS와 명시적 `owner-token` 모드입니다. `PUBLIC_ORIGIN`은 서버에 설정한 실제 HTTPS origin을 뜻하며 이 문서에는 운영 주소나 비밀값을 넣지 않습니다. [실행 42125582058](https://github.com/Hyunwoo1205/quanta/actions/runs/42125582058)은 인증서 발급·화면 응답·익명 및 잘못된 토큰의 401을 확인했습니다. 올바른 소유자 키를 사용한 브라우저·모바일·계산 확인은 아직 대기 중입니다.

## 최초 연결

1. 사용자의 기존 신뢰한 PuTTY SSH 세션에서 아래 명령을 실행합니다. 전체 환경 파일 대신 `QUANTA_OWNER_TOKEN`의 값 하나만 그 개인 터미널에 표시합니다. 명령은 파일을 수정하지 않습니다.

   ```bash
   sudo sed -n 's/^QUANTA_OWNER_TOKEN=//p' /etc/quanta/app.env
   ```

2. 본인 브라우저에서 `PUBLIC_ORIGIN`을 열고 HTTPS 주소와 인증서 경고가 없는지 확인합니다. 화면의 **소유자 접근 키** 입력란에 표시된 키를 비공개로 붙여넣고 **연결하기**를 누릅니다. 키를 채팅·공유 화면·스크린샷·저장소·공개 로그·공개 자동검사에 보내지 않습니다.
3. **계산 환경 연결됨** 표시, 패키지 버전과 저장한 실험·실행 목록을 확인합니다. 첫 사용의 빈 목록은 정상일 수 있습니다. 화면이 열렸다는 사실과 인증 후 목록을 조회한 사실을 별도로 기록합니다.

키는 열린 페이지의 메모리에만 보관합니다. 새로고침·연결 해제 후에는 다시 입력하며, 연결 해제는 서버의 실행을 취소하지 않습니다. 새 키·새 SSH 연결 방식·추가 인증 기능을 만들 필요는 없습니다. 키가 출력되지 않거나 연결이 실패하면 값 대신 명령 오류 여부·화면 오류·실패 단계를 보고합니다.

## 실제 확인 항목

개인 검증 기록에는 시간·브라우저·기기 종류, 수행 항목·결과·오류와 필요한 비밀값 없는 실행 식별자만 남깁니다. 아래 각 항목은 실제 수행 전까지 미확인입니다.

| 항목 | 확인할 동작 |
|---|---|
| 입력·검증·저장 | 지원 예제를 불러오거나 입력을 작성해 검증하고 저장합니다. 저장한 revision과 편집 중 초안이 구분되는지 확인합니다. |
| 계산 | 저장본을 실행해 진행·종료 상태와 실제 결과를 확인합니다. 실패했다면 오류·부분 결과를 보존하며 성공으로 바꾸지 않습니다. |
| 결과 의미 | 실행·수치·해상도·물리 상태가 각각 표시되고 물리 검증은 `unvalidated`인지 확인합니다. 실제 단계·분기의 수치와 표·그래프를 봅니다. |
| 기록·다운로드 | 실행 기록을 다시 열고 원본 결과와 산출물을 내려받습니다. 산출물의 크기·SHA 확인이 실패하지 않는지 확인합니다. |
| 재실행 | 같은 저장 입력의 재실행으로 새 실행이 생기며 이전 기록이 보존되는지 확인합니다. |
| 취소 | 실행 중인 별도 작업에 취소를 요청하고 종료 상태·완료된 부분 결과·이후 상태를 확인합니다. 너무 빨리 끝난 작업은 취소 합격으로 기록하지 않습니다. |
| 재인증·데이터 보존 | 필요한 초안을 먼저 내보낸 뒤 새로고침합니다. 재인증이 필요하고 연결 후 서버의 저장본·기록을 다시 조회할 수 있는지 확인합니다. |
| 모바일 | 실제 모바일 브라우저에서 비공개 인증·입력·저장·계산·결과·다운로드를 확인하고 가로 넘침이나 조작 오류를 기록합니다. 화면 폭만 줄인 데스크톱 확인과 구분합니다. |

중복 제출이나 연결 오류가 발생하면 먼저 실행 기록을 조회하고 계산이 수락됐는지 확인합니다. 확인 없이 같은 작업을 반복 제출하지 않습니다. 이 확인을 위해 앱·방화벽·백업·ACME를 다시 설치하지 않습니다.

이 문서는 확인 절차이며 수행 결과가 아닙니다. 실제 브라우저 합격·모바일 합격·계산 합격은 별도 근거가 생긴 뒤 갱신합니다. 같은 부트 파일시스템 안의 기존 분리 복구 성공은 off-host 백업·전체 볼륨 복원·실제 OS 재부팅 검증을 뜻하지 않습니다.

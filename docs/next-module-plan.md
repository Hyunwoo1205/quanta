## 계산 규칙

입력 척도는 길이 `L0`, 에너지 `E0`이며, 두 대상 사이의 무차원 거리는 `rho = distance_m/L0`입니다.

```text
U = E0 × sum(i < j, f(rho_ij))
F_i_from_j = -(E0/L0) × f'(rho_ij) × (r_i-r_j)/distance_ij
F_j_from_i = -F_i_from_j
```

각 쌍을 한 번만 에너지에 더하고 힘은 반대 부호로 두 대상에 누적합니다. 힘은 좌표 순서와 대응되어야 합니다. 고정 마스크는 반력에 해당하는 출력을 없애지 않습니다.

자동미분은 `const`, `var`, `param`과 등록된 산술·지수·로그·제곱근·삼각 연산을 모두 다룹니다. 정수 지수의 음수·0·양수, 중첩식, 매개변수와 연쇄 법칙을 확인합니다. 해석식과 유한차분은 독립적인 시험 기준으로 사용하며 운영 계산의 조용한 대체 경로로 사용하지 않습니다.

충돌·최소 거리 위반, 0으로 나눔, 등록된 `log`·`sqrt` 정의역 위반, 값 또는 도함수의 비유한 결과, SI 복원·합산의 수치 범위 이탈은 명시적 오류로 처리합니다. 입력 좌표와 작성 정의는 변경하지 않습니다.

## 출력 기준

등록된 `module_results/pair_static.schema.json`의 필수 payload를 채웁니다. `energy_forces`에서는 다음 의미를 고정합니다.

- `initial_positions_m`와 `final_positions_m`은 입력 배치와 동일합니다.
- `iterations=0`, `evaluations=1`이며 평가 횟수는 전체 에너지·힘 함수의 호출 횟수입니다.
- `free_gradient_inf`는 자유 좌표의 무차원 에너지 기울기 최대 절댓값입니다. 모두 고정된 배치에서는 0입니다.
- `minimum_confirmed=false`이며 지정 배치의 평가를 최적화 수렴이나 안정성 확인으로 표시하지 않습니다.
- 요청된 쌍별 에너지만 선택 출력으로 추가하고 최적화 이력은 생성하지 않습니다.
- 구조 스키마 외에도 입자 수·배열 형상·인덱스·쌍 중복·단위·유한값을 확인합니다.

실제 실행 시스템이 아직 없는 단일 평가에서 run·state 식별자와 실행 계획·미래 상태 해시를 꾸며 생성하지 않습니다. 작성 정의의 해시와 모듈·코드·환경 근거를 평가 기록에 연결하고, 실제로 호출한 범위만 명시합니다.

## 수치 검증 기준

기존 `validation_manifest.json`의 A01~A03을 적용합니다. 아래 허용오차는 지정한 매끄럽고 적절히 스케일된 기준 문제의 무차원 값에 적용하며, 작은 SI 에너지·힘에 같은 절대 허용오차를 그대로 적용하지 않습니다.

| 기준 | 확인 내용 | 합격 목표 |
|---|---|---|
| A01 | 조화 쌍 모형의 독립적인 해석식과 에너지·힘 비교 | 성분별 `atol=1e-10`, `rtol=1e-10` |
| A02 | 위치별 중심 유한차분과 힘의 관계 | 간격 `1e-4`, `1e-5`, `1e-6`; 정규화 잔차 `<=1e-6`, 이웃한 두 간격에서 만족 |
| A03 | 병진·회전·입자 순서 변경, 전체 내부 힘·토크 | 정규화 최대 잔차 `<=1e-10`; 순서 변경 후 힘 배열의 대응도 확인 |
| 단위 동등성 | 같은 물리 조건을 다른 `L0/E0`로 표현 | 무차원 계수를 함께 변환한 뒤 SI 결과의 동등성 확인 |
| 연산·오류 경로 | 모든 AST 연산, 경계·충돌·비유한 값, 결과 계약 | 독립 기준과 명시적 오류 반환; 기존 회귀 시험 유지 |

토크는 `L0 × (E0/L0) = E0`, 힘은 `E0/L0`를 기준으로 정규화합니다. 시험 기록에는 입력·기준값·실제값·오차·허용오차·판정·코드·환경을 남깁니다. 입력 변경 없이 허용오차를 완화해 실패를 숨기지 않습니다.

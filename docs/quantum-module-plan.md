# 양자 정적 상태 계산 모듈 구현 계획

작성일: 2026-11-04 · 기준 commit: `25b5ae0342b821dbb98a1313277b00ffd7c42d48`

## 목표와 범위

동봉 계약 `0.2.0`에 등록된 `quanta.quantum_stationary@0.1.0`의 `eigenstates`를 실제 구현합니다. 유한한 1차원 구간, 실수 퍼텐셜, 양 끝 파동함수 0의 조건에서 낮은 에너지 상태를 계산합니다. 사용자가 질량·구간·지원 수식·상태 수·격자와 허용오차를 지정합니다. 플랫폼 전체의 표현·차원·경계를 이 첫 모듈에 제한하지 않습니다.

단일 초기 단계의 Python API·CLI, 검증된 결과 payload, 실행·수치·격자 해상도의 분리 판정, B01~B06 실측과 설치·CI를 이번 완료 범위로 삼습니다. 다단계·반복 축 실행, 시간 변화, 모형 사이 물리적 결합, 서버·웹 화면은 별도 단계입니다. 가져온 계약의 원본·계획 상태는 보존합니다.

## 계산 결정

- `xi=(x-a)/L0`, `B=(b-a)/L0`, `V(x)=E0*v(xi)`와 `alpha=hbar²/(2*m*E0*L0²)`를 사용합니다. `h=6.62607015e-34 J s`, `hbar=h/(2*pi)`를 binary64로 계산합니다.
- n개 내부 균등 격자에서 2차 중심차분을 사용합니다. 주대각은 `2*alpha/dxi²+v`, 양옆 대각은 `-alpha/dxi²`입니다.
- 잠금된 SciPy의 `eigh_tridiagonal`, `select='i'`, `select_range=(0,K-1)`, `lapack_driver='stebz'`, `check_finite=True`로 낮은 K개 고유쌍을 계산합니다. 다른 solver로 조용히 대체하지 않습니다.
- 격자 가중 정규화 후 SI 파동함수 단위는 `m^-1/2`, 확률밀도는 `m^-1`입니다. 각 상태의 절댓값이 가장 큰 첫 격자 성분을 양수로 정합니다. 실수 문제의 허수 성분은 0입니다.
- 매 격자의 정규화·직교성 오차 `1e-10`, 정규화 고유방정식 잔차 `1e-12`를 확인합니다. 요청된 세분화의 마지막 두 인접 격자에서 모든 상태의 무차원 에너지 차이가 `atol+rtol*abs(Efine)` 이하일 때 해상도 수렴입니다. 세분화 0회는 해상도 `not_checked`입니다.
- n은 31~4095, 상태 수는 `min(16,n-2)` 이하이며 세분화는 최대 2회입니다. 최종 내부 격자 `(n+1)*2^levels-1`도 4095 이하입니다. 상한 초과를 자동 축소하지 않습니다.

## 구현 순서와 합격 조건

| 순서 | 작업 | 합격 조건 |
|---|---|---|
| 1 | 입력·단위·격자·수식 경계 | 기존 검증기와 실행 계산 정책 일치, 정의역·비유한 값·자원 초과 명시적 오류 |
| 2 | 삼중대각 계산과 SI 결과 | 낮은 상태·경계·상태 정규화·선택 관측량·결과 스키마 및 형상 검사 |
| 3 | 격자 세분화와 상태 판정 | 수치 유효성과 해상도 판정을 분리, 실패 시 마지막 유효 격자만 부분 결과 |
| 4 | 독립 검증 | B01~B06 원래 기준 유지, 기존 A01~A04·SI 및 회귀 시험 통과 |
| 5 | 실행 경로와 기록 | 단일 단계 API·CLI, 실제 측정 기록·코드/환경 해시, 최종 wheel 설치와 원격 CI 통과 |

수치 시험 합격을 실제 현상 비교의 물리 검증으로 표시하지 않습니다. 상태가 유효하더라도 격자 수렴 실패는 전체 실행 실패로 기록하며, 부분 결과와 이미 확인된 진단을 보존합니다. 미실행 기준이나 미래 모듈의 상태를 완료로 바꾸지 않습니다.

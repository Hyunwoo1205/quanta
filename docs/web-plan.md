# 웹 작업 화면 구현 계획

작성일: 2026-11-04 · 기준 소스: `d6debad0c6e263b315af65609466479e07fc5555`

기존 로컬 실행 서비스를 브라우저에서 사용하도록 실험 구성·입력 검증·불변 revision 저장·비동기 실행·결과 조회 화면을 구현합니다. 현재 Python 서버가 정적 화면과 API를 같은 출처에서 제공하며, 공개 배포·외부 계정은 별도 단계로 유지합니다.

| 순서 | 구현과 완료 기준 |
|---|---|
| 1 | 패키지에 포함한 HTML·CSS·JavaScript와 기존 예제를 같은 서버에서 제공 |
| 2 | 메모리 안의 bearer 인증, 실험·revision·실행 기록 조회, JSON 편집·오류 표시 |
| 3 | 저장한 입력으로만 실행, 중복 요청 재시도, 진행·취소·재실행, 기록 재조회 |
| 4 | 실행·수치·해상도·물리 상태 구분, 단계·분기별 실제 표·그래프·산출물 다운로드 |
| 5 | HTTP·브라우저 상태·원본 수치 보존·설치 패키지·회귀와 CI 검증 |

작성 중 입력과 저장한 revision, 조회 중 실행과 결과의 식별자를 구분합니다. 늦게 도착한 응답이 다른 실험·실행을 덮어쓰지 않도록 검사하고, 입력을 수정하면 저장 전 실행을 막습니다. `-0.0` 등 실제 기록의 숫자를 UI의 JSON 왕복에서 잃지 않도록 확인합니다.

브라우저에 토큰을 영구 저장하지 않고 URL·로그·HTML에 넣지 않습니다. 계산 API는 인증을 유지하고 서버는 Host·Origin과 정적 자원 경로를 검사합니다. 외부 스크립트·CDN·원격 수식 실행을 사용하지 않습니다.

새 과학 모형이나 계산식은 추가하지 않습니다. 기존 기준을 유지하며 검증한 실제 결과만 표시합니다. 첫 입력 방식은 전체 명세를 편집할 수 있는 JSON과 동봉 예제이며 모든 미래 모듈을 현재 양식에 제한하지 않습니다.
